# Architecture

Цей каталог призначений для похідних архітектурних моделей OCP:

- context і container diagrams;
- knowledge graph projections;
- state machines;
- sequence diagrams;
- capability boundaries;
- deployment models.

Архітектурні артефакти не можуть переозначати канонічні поняття з `docs/000-operational-ontology/`.

AD-052's executable `constraint-document-status-readiness` witness derives document-status criteria only from current OCP-001/OCP-016, separates them from stable-surface discovery vocabulary, scans every Accepted/Canonical primary OCP for current open-question carriers, and applies Accepted and Canonical requirements to OCP-006 independently without changing its lifecycle.
