# OCP Fundamental

**Operational Coordination Platform (OCP)** — платформа оперативної координації, що моделює реальний операційний простір та взаємодію сил і засобів.

Цей репозиторій містить фундаментальні онтологічні, архітектурні та інженерні специфікації OCP. Операційні дані, реальні координати, відомості про підрозділи та інші чутливі матеріали тут не зберігаються.
