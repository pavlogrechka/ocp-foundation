# Architecture Decision Records

Цей каталог містить формальні архітектурні рішення OCP.

## Правило

- `Draft` — рішення обговорюється та не є обов’язковим.
- `Accepted` — рішення затверджене Architecture Board.
- `Superseded` — замінене новим ADR.
- `Deprecated` — не застосовується до нових рішень.

| ADR | Назва | Статус |
|---|---|---|
| ADR-000 | Reality Before Software | Accepted |
| ADR-001 | Domain-Driven First | Accepted |
| ADR-002 | OCP Is a Framework | Accepted |
| ADR-003 | Ontology as Knowledge Graph | Accepted |
| ADR-004 | Question-Driven Architecture | Accepted |
| ADR-005 | Four Worlds Model | Accepted |
| ADR-006 | AI Is Design-Time Only | Accepted |
| ADR-DRAFT-007 | State as a Concept | Superseded |

Жоден Accepted ADR не змінюється без нового ADR, який його уточнює або замінює.
