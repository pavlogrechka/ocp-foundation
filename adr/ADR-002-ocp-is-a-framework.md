# ADR-002 — OCP Is a Framework

- **Status:** Accepted
- **Date:** 2026-08-02

## Decision

OCP є універсальною платформою операційної координації. Предметна специфіка БпС, РЕБ, спектра та інших напрямків реалізується через окремі Capability.

## Consequences

- Core не містить логіки конкретного виду діяльності.
- Нові предметні області додаються без руйнування фундаментальної моделі.
