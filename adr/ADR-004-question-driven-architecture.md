# ADR-004 — Question-Driven Architecture

- **Status:** Accepted
- **Date:** 2026-08-02

## Decision

Кожна Capability OCP повинна відповідати щонайменше на одне канонічне операційне питання користувача.

## Consequences

- Архітектура не будується навколо CRUD, таблиць або екранів.
- Функції без чіткої операційної цінності підлягають перегляду.
