# ADR-000 — Reality Before Software

- **Status:** Accepted
- **Date:** 2026-08-02

## Decision

OCP проєктується як формальна модель операційної діяльності. Програмне забезпечення є реалізацією цієї моделі, а не джерелом її визначень.

## Consequences

- Operational Ontology є джерелом істини.
- Предметна область має пріоритет над базою даних, API та UI.
- Нові функції спочатку формалізуються як поняття, правила або Capability.
